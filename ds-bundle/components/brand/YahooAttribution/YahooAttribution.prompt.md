YahooAttribution from @laces-out/web. Use via `window.LacesOut.YahooAttribution` (bundle loaded from the root `_ds_bundle.js`).

The required "data provided by Yahoo" attribution line.

Yahoo's developer terms require visible attribution wherever Yahoo league data
is shown. Render this once per surface that displays Yahoo-sourced data —
typically in the footer of a panel or page. It links out and carries its own
external-link icon.

## Props

```ts
interface YahooAttributionProps {
  /* Takes no props — the required Yahoo data-source attribution line. */
}
```
